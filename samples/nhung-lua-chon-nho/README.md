62,3 giây · 1920×1080 · 30 fps · H.264 + AAC.

Nếu GitHub không phát MP4 trực tiếp, chọn **Download raw file** hoặc tải qua liên kết phía trên.

Bản mới dùng 62,3 giây đầu file 1.MP3 được cung cấp, giữ tốc độ và chuẩn hóa âm lượng. Các khoảng ngắt được đối chiếu với SRT; chưa kiểm chứng bằng nghe/phiên âm từng từ. Nhân vật và bối cảnh được tạo bằng AI theo phong cách hoạt hình có nét mặt, trang phục, đổ bóng và không gian đời thực. Đây là minh họa có chuyển động camera, không phải phim quay thực hay hoạt hình khẩu hình. Hình từng cảnh được phóng lên kích thước xuất 1080p.

Giải nén ZIP, chạy `npm ci`, rồi `npm run dev -- src/index.tsx`. Đọc README trong ZIP để chạy render; cần Chromium (mặc định /usr/bin/chromium).
